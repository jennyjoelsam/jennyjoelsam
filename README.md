## Featured project

### [Knowledge Base API](https://github.com/jennyjoelsam/kb-api)

A FastAPI + SQLite REST service for storing and searching text documents. It is the foundation for a RAG support assistant I'm building next.

- CRUD with Pydantic validation, tag filtering and pagination
- Ranked keyword search (title 3x, tag 2x, body 1x)
- 32 pytest tests run on every push by GitHub Actions
- Dockerfile, environment-based config, request logging, health check
- Layered structure: web, schemas, database and search code are separate
- README lists known limitations and a roadmap

![tests](https://github.com/jennyjoelsam/kb-api/actions/workflows/tests.yml/badge.svg)

**Next:** BM25 + embedding search, then RAG answers with citations and an evaluation set.
